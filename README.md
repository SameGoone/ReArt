Данный репозиторий - backend часть проекта **ReArt**.

**ReArt** - Социальная сеть для цифровых художников с возможностью создать портфолио работ и получать обратную связь. Это прокаченная версия [дипломной работы](https://github.com/SameGoone/Artbuk), переписанная с применением современных паттернов и технологий.

[Frontend на React](https://github.com/SameGoone/ReArt_client_react)

[Frontend на Angular](https://github.com/SameGoone/ReArt_client_angular)


Проект построен на **Clean Architecture** с применением паттерна **Mediator**.

**Стек**: ASP.Net, Entity Framework, SignalR, JWT-аутентификация, xUnit, Moq
